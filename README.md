# NER Landslide — Data Foundation (Milestone 1)

Real data, built 2026-09-02. The `MOCK_*` files from day one are **superseded**;
delete them (`git rm`, see below).

## Read this first

**[`docs/FINDINGS.md`](docs/FINDINGS.md)** — the open inventory cannot carry a
90 m terrain-based susceptibility model, and the reason changes what we build.
Slope scores an AUC of 0.507 against these labels. Read it before writing any
modelling code.

## Build it

```bash
pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File scripts\organise_raw.ps1   # Windows, once
python run_pipeline.py
```

Takes about six minutes, most of it terrain. Ends with 14/14 integrity checks,
including no spatial leakage between splits.

## The dataset

1,029 rows — 341 landslides and 688 sampled non-landslides across the eight NER
states, 2007–2017. Nine terrain features from a 90 m DEM, seven rainfall
features from IMD's daily grid, state and district, a per-event location-accuracy
weight, and a 25 km spatial block id.

Baseline on the blocked test set (172 rows, base rate 0.297):

| features | logistic regression | gradient boosting |
|---|---|---|
| terrain only | 0.614 | 0.749 |
| rainfall only | 0.491 | 0.637 |
| both | 0.602 | 0.749 |

**Do not quote 0.749 without reading section 3 of FINDINGS.md.** Every terrain
feature is individually at ~0.50, so the boosted model is fingerprinting
location, not learning slope physics.
